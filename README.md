# greeter

A tiny CLI that prints a friendly greeting.

## Install

```
git clone https://github.com/EddsyinDevelopment/greeter.git
cd greeter
npm install
npm run build
```

## Usage

```
node dist/index.js Eddy
# Hello, Eddy! 👋

node dist/index.js Eddy --shout
# HELLO, EDDY! 👋
```

## Options

- `--shout` — uppercase the greeting.
